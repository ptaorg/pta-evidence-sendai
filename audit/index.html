立場別
PTA運営セルフ監査

保護者、PTA役員、学校管理職、教育委員会の4つの立場で、PTA運営のリスクを質問形式で点検します。

立場を選んで診断する

同じPTA問題でも、確認者の立場によって、見える資料、聞ける相手、整理すべき責任範囲が変わります。該当する立場の診断を開き、結果は「結論」ではなく「次に確認する資料リスト」として扱います。

このページで診断の使い方を確認したうえで、実際に診断を始める立場を選んでください。迷う場合は、実際に資料を持っている立場から始めます。

👨‍👩‍👧 保護者向け監査入会意思、会費、個人情報、非会員児童の扱いを点検します。 → 🗂️ PTA役員向け監査会員管理、会計開示、学校依存、個人情報、規約・役員選出を点検します。 → 🏫 学校管理職向け監査学校徴収金、校務分掌、個人情報、学校資源利用を点検します。 → 🧭 教育委員会向け監査各校のPTA関与状況、通知、点検票、改善指示を点検します。 →

診断結果は「資料確認表」に変換する

高リスク項目が出た場合でも、そこで結論を出すのではなく、資料名、作成主体、日付、担当主体、未確認事項を整理します。診断は、適法・違法の結論を自動で示すものではありません。外部へ提出する場合は、診断結果をそのまま貼るのではなく、事実確認の質問に変換してください。

  1. 高リスク項目を、入会、会費、個人情報、教職員関与、学校資源利用に分類します。
  2. 確認済み資料、未確認資料、口頭説明だけの事項を分けます。
  3. PTAへ確認する事項、学校へ確認する事項、教育委員会へ確認する事項を分けます。
  4. 回答が曖昧な場合は、回答DB、提出キット、情報公開請求キットへ接続します。

立場別に確認する資料

立場最初に確認する資料確認の焦点次に進む先
保護者入会案内、入会申込書、会費通知、個人情報同意書、自分の提出記録。自分の加入意思、請求根拠、個人情報利用、非会員・退会時の扱いを分けます。保護者向けガイド
PTA役員会則、会員名簿、会計資料、個人情報規程、役員選出資料。学校依存の部分を見つけ、PTA自身で説明・管理できる事務へ戻します。PTA役員向けガイド
学校管理職校務分掌、学校徴収金資料、学校HP・配信記録、個人情報提供記録。PTA内部事務と学校の連絡調整を分け、学校側が関与している範囲を確認します。学校・教育委員会向け
教育委員会各校照会票、通知、要綱、学校回答、開示資料、改善記録。PTAの直接統制ではなく、学校側関与、服務、個人情報、徴収事務の点検として扱います。教委・学校チェックリスト

診断項目と資料の対応

診断で示される項目は、すべて資料確認に戻して扱います。加入の項目であれば入会申込書、会費の項目であれば徴収資料、個人情報の項目であれば同意書と提供記録、教職員関与の項目であれば校務分掌や勤務時間中の事務記録を確認します。

入会入会届、加入意思確認、退会方法、会則
会費会費通知、総会資料、学校徴収金との区分、返金・未納対応
個人情報取得元、利用目的、同意書、PTAへの提供記録
教職員関与校務分掌、勤務時間中の事務、委任・覚書、職務専念義務免除の有無
学校資源学校HP、配信アプリ、配布物、施設利用、学校名義との混在

診断の位置づけ

このページは、PTA運営上の確認事項を整理するための点検入口です。診断結果は法的判断そのものではなく、どの資料を先に確認すべきか、どの論点を教育委員会・学校・PTAに照会すべきかを整理する補助として使います。

保護者、PTA役員、学校管理職、教育委員会では、同じ事実でも確認すべき資料が異なります。立場を選んだうえで、加入、会費、個人情報、教職員関与、学校資源利用の順に点検してください。
